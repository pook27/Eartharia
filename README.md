🌍 Eartharia
Eartharia is a web-based sandbox survival game inspired by Terraria. Built entirely in React and TypeScript using a custom HTML5 Canvas engine, it brings the core "mine, craft, build" experience directly to the browser.

✨ Features
Procedural World Generation: Explore unique worlds with different biomes, underground caves, and ores.

Custom Game Engine: A performant 2D engine handling physics, collisions, and entity management from scratch.

Dynamic Lighting: Real-time tile-based lighting system with day/night cycles.

Crafting System: Gather resources to craft tools, weapons, and furniture. Includes support for specific crafting stations.

Combat & Enemies: Fight various enemies like Slimes, Zombies, and Demon Eyes using melee and ranged weapons.

NPC Interaction: Interact with friendly NPCs (Guide, Merchant, Nurse) including a functional Shop system.

Inventory Management: Full inventory system with equipment slots (Armor, Accessories), hotbar, and chest storage.

Smart Cursor: Toggleable auto-targeting to assist with mining and placement.

🛠 Tech Stack
Frontend: React 19

Language: TypeScript

Build Tool: Vite

Rendering: HTML5 Canvas (2D Context)

Styling: Tailwind CSS

🚀 Getting Started
Prerequisites
Node.js (v16+ recommended)

npm

Installation
Install dependencies:

Bash

npm install
Run the development server:

Bash

npm run dev
Build for production:

Bash

npm run build
